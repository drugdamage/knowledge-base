# IT notes

Все заметки — в одном Word-файле: **[IT notes.docx](IT%20notes.docx)**.

Темы: «Коммутатор и маршрутизатор», «Уровни модели OSI», «Сетевые протоколы» и «VPN». Для каждой сначала идёт объяснение на русском, затем английская версия. В документе есть таблицы и схема сети; каждая новая тема начинается с новой страницы.

Добавлен блок из 17 тем для подготовки к ВКР о локальном менеджере паролей: свойства безопасности, модель угроз, математическая база, шифрование и хэширование, «Кузнечик», «Стрибог», HMAC, парольная KDF, режимы шифрования, MGM, случайность и nonce, управление ключами, формат хранилища, защита секретов в памяти, надёжная запись и резервирование, проверка реализации и стандарты. В каждой теме есть объяснение, таблица, вопросы для самопроверки и ссылки на источники; русский текст сопровождается английским переводом.

Каждая из 21 темы дополнена разбором простыми словами, бытовыми аналогиями, практическими ситуациями и объяснением типичных ошибок. Поясняются также границы применимости аналогий: они помогают понять механизм, но не заменяют его точное описание. Сначала полностью идёт русская версия темы, затем английская.

## Как добавлять темы

Скачай файл и открой в Word. В конце добавь название новой темы со стилем **Заголовок 1** — этот стиль автоматически начинает новую страницу. Ниже запиши текст на русском, затем его английскую версию. Для ручного разрыва страницы: **⌘ + Enter** на Mac или **Ctrl + Enter** на Windows.

Сохрани изменения и загрузи обновлённый файл в этот репозиторий, заменив предыдущий. GitHub хранит историю версий; редактировать сам документ удобнее в Word.
