## Как вести заметки

Одна тема — один файл `.md`. Markdown — обычный текст с простым оформлением: GitHub сам показывает заголовки, таблицы и примеры кода.

**Дополнить заметку:** открыть файл на GitHub → нажать значок карандаша → внести изменения → сохранить через **Commit changes**. История изменений останется в репозитории.

**Добавить тему:** скопировать [шаблон](templates/note.md), создать файл через **Add file → Create new file**, вставить текст и сохранить. В имени файла можно сразу указать папку, например `notes/networks/dns.md`. Затем добавить ссылку в таблицу выше.

Разделы можно добавлять по мере необходимости: `networks`, `security`, `linux`, `programming`, `databases`, `testing`. Необязательно заполнять весь шаблон — достаточно понятного объяснения и примера.
