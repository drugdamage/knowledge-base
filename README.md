## Результаты подготовки

- Разобраны метод, путь, заголовки, тело запроса и HTTP-статус.
- Разобрано различие между `Set-Cookie` и `Cookie`, а также связь cookie с сессией.
- Найден и повторно отправлен штатный `POST /product/stock` через Burp Repeater. Получен ответ `200 OK` с телом `170`.
- Изучены основы SSRF и CSRF, назначение allowlist, CSRF-токена и SameSite.
- Выполнен разбор условного сценария: сервер сообщает `403`, но изменение почты всё равно происходит.
- Отработано различие между фактом, предположением и возможным последствием.

## Статус практики

Отчёт по Burp описывает выполненную проверку обычного HTTP-запроса. Лаборатория SSRF не завершена; уязвимость этой проверкой не подтверждена.

Материал по CSRF — разбор условий учебной задачи. Практическое воспроизведение CSRF на сайте не выполнялось.

## Принцип работы с отчётами

Вывод должен соответствовать доказательствам. Код HTTP фиксируется вместе с содержимым ответа и фактическим состоянием приложения. Возможное воздействие описывается отдельно от подтверждённого результата.
