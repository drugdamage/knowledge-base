# Идентификация, аутентификация и авторизация

- **Идентификация** — пользователь указывает логин, и система определяет, о какой учётной записи речь.
- **Аутентификация** — система проверяет, что пользователь действительно тот, за кого себя выдаёт. Для этого может использоваться пароль, ключ или код.
- **Авторизация** — система проверяет, какие действия и ресурсы доступны этой учётной записи.

Например, ученик указывает логин и подтверждает вход кодом. После входа система разрешает ему просматривать свои оценки, а учителю — редактировать оценки по своим предметам.
