# OWASP Top 10:2025

OWASP Top 10 — список десяти категорий рисков безопасности веб-приложений, который публикует OWASP. Ниже категории выпуска 2025 года с учебными примерами. [Официальный список OWASP](https://top10.owasp.org/2025/)

## A01 — Broken Access Control

Нарушение контроля доступа. Приложение разрешает чтение данных или выполнение действий без проверки нужных прав. В эту категорию OWASP также включает CSRF, SSRF и Directory Traversal. [OWASP — A01](https://top10.owasp.org/2025/A01_2025-Broken_Access_Control/)

**Пример.** Пользователь видит счёт другого клиента. Сервер проверяет наличие сессии, а проверка прав на конкретный счёт пропущена.

Связанные заметки — [CSRF](CSRF.md), [SSRF](SSRF.md), [Directory Traversal](DIRECTORY_TRAVERSAL.md).

## A02 — Security Misconfiguration

Небезопасная конфигурация. Настройки приложения, сервера или облака открывают лишние возможности или данные. [OWASP — A02](https://top10.owasp.org/2025/A02_2025-Security_Misconfiguration/)

**Пример.** В рабочей среде включён режим отладки. На странице ошибки посетитель видит внутренние пути к файлам и детали конфигурации.

## A03 — Software Supply Chain Failures

Проблемы в цепочке поставки ПО. Риск возникает в зависимостях, при сборке или распространении приложения. [OWASP — A03](https://top10.owasp.org/2025/A03_2025-Software_Supply_Chain_Failures/)

**Пример.** В сборку попала скомпрометированная версия сторонней библиотеки, и вредоносный код распространился вместе с приложением.

## A04 — Cryptographic Failures

Недостатки криптографической защиты при передаче или хранении данных. Например, шифрование отсутствует или настроено небезопасно. [OWASP — A04](https://top10.owasp.org/2025/A04_2025-Cryptographic_Failures/)

**Пример.** Приложение передаёт персональные данные по HTTP без шифрования. Участник сети, который может наблюдать этот трафик, видит содержимое запроса.

## A05 — Injection

Инъекция. Приложение передаёт недоверенные данные интерпретатору в форме, которая позволяет данным изменить смысл команды или разметки. К этой категории относится и XSS. [OWASP — A05](https://top10.owasp.org/2025/A05_2025-Injection/)

**Пример.** Сайт формирует SQL-запрос, подставляя в него строку поиска. Введённый текст может изменить смысл запроса к базе.

[Подробнее о XSS](XSS.md)

## A06 — Insecure Design

Небезопасное проектирование. В правилах работы функции отсутствует проверка или ограничение, необходимое для защиты. [OWASP — A06](https://top10.owasp.org/2025/A06_2025-Insecure_Design/)

**Пример.** Сервис бронирования разрешает одному пользователю занять любое количество мест без оплаты. Остальным пользователям может не хватить мест.

## A07 — Authentication Failures

Ошибки проверки личности или управления сессией. В результате кто-то может получить или сохранить доступ от имени другого пользователя. [OWASP — A07](https://top10.owasp.org/2025/A07_2025-Authentication_Failures/)

**Пример.** Пользователь вышел из аккаунта, а сервер продолжает принимать идентификатор завершённой сессии.

## A08 — Software or Data Integrity Failures

Нарушение целостности ПО или данных. Приложение доверяет коду или данным без достаточной проверки их происхождения и целостности. [OWASP — A08](https://top10.owasp.org/2025/A08_2025-Software_or_Data_Integrity_Failures/)

**Пример.** Сервис автообновления устанавливает пакет без проверки цифровой подписи. Подменённый пакет принимается как подлинный.

## A09 — Security Logging and Alerting Failures

Недостатки журналирования и оповещений. Команда пропускает подозрительную активность из-за отсутствия нужных записей или уведомлений. [OWASP — A09](https://top10.owasp.org/2025/A09_2025-Security_Logging_and_Alerting_Failures/)

**Пример.** Журнал содержит только успешные входы. Серия неудачных попыток проходит без записи и оповещения команды.

## A10 — Mishandling of Exceptional Conditions

Небезопасная обработка исключительных ситуаций. При ошибке, тайм-ауте или неожиданном состоянии приложение теряет предусмотренные ограничения. [OWASP — A10](https://top10.owasp.org/2025/A10_2025-Mishandling_of_Exceptional_Conditions/)

**Пример.** Сервис проверки прав не ответил вовремя. Приложение по умолчанию разрешило открыть закрытый документ.
