# XSS (Cross-Site Scripting)

XSS — уязвимость, при которой приложение обрабатывает недоверенные данные так, что браузер выполняет внедрённый код в контексте сайта. Этот код может читать доступные странице данные или выполнять действия от имени пользователя.

**Пример.** Сайт вставляет комментарий в HTML страницы без нужной обработки, и браузеры посетителей выполняют код из этого комментария. [OWASP — Cross-Site Scripting](https://community.owasp.org/attacks/xss/)

## Виды XSS

- **Хранимая (Stored)** — приложение сохраняет введённые данные, например в комментарии, и показывает их посетителям позже.
- **Отражённая (Reflected)** — данные из запроса попадают в страницу, которую приложение возвращает сразу.
- **DOM-based** — данные небезопасно обрабатывает код самой страницы в браузере. Такой вариант может быть хранимым или отражённым. [OWASP — DOM-based XSS](https://cheatsheetseries.owasp.org/cheatsheets/DOM_based_XSS_Prevention_Cheat_Sheet.html)

**Противодействие** — экранировать данные с учётом места вывода, для обычного текста использовать `textContent`, а пользовательский HTML очищать через санитайзер. Политика Content Security Policy (CSP) служит дополнительной защитой. [OWASP — защита от XSS](https://cheatsheetseries.owasp.org/cheatsheets/Cross_Site_Scripting_Prevention_Cheat_Sheet.html)
