# Триаж

Триаж — первичный разбор входящего баг-репорта.

При триаже проверяют, входит ли затронутая функция в область программы, есть ли похожий отчёт и достаточно ли сведений для проверки. Затем оценивают влияние и определяют приоритет разбора. [HackerOne — Quality Reports](https://docs.hackerone.com/en/articles/8475116-quality-reports)
