# Различие между CSRF и SSRF

Главное различие — кто отправляет нежелательный запрос.

- **CSRF** — сторонняя страница побуждает браузер отправить запрос к приложению в активной сессии пользователя. [Подробнее о CSRF](CSRF.md)
- **SSRF** — сервер приложения сам отправляет запрос к другому ресурсу, используя свой сетевой доступ. [Подробнее о SSRF](SSRF.md)
