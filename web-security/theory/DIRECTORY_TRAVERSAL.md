# Directory Traversal (Path Traversal)

Directory Traversal — уязвимость, при которой приложение строит путь к файлу из пользовательских данных и обращается за пределы разрешённого каталога. В зависимости от операции и прав приложения это может привести к чтению или изменению файлов в других каталогах.

**Пример.** Функция скачивания документов возвращает файл конфигурации, который хранится за пределами папки с документами.

**Противодействие** — принимать идентификатор файла и выбирать соответствующий путь на сервере. Если приложение принимает имя файла, нужно вычислить итоговый путь с учётом символических ссылок и убедиться, что он находится внутри разрешённого каталога.
