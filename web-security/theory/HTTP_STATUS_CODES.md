# Коды ответа HTTP

Код ответа — трёхзначное число, которым сервер сообщает результат обработки HTTP-запроса. Первая цифра определяет группу.

## 2xx — успешная обработка

Сервер получил, понял и принял запрос. Конкретный код уточняет, завершено ли действие и что вернул сервер.

| Код | Значение |
| --- | --- |
| `200 OK` | Запрос выполнен успешно. Например, сервер вернул запрошенную страницу. |
| `201 Created` | Создан ресурс, например новый комментарий. |
| `202 Accepted` | Запрос принят, обработка ещё не завершена. Например, запрос на формирование отчёта поставлен в очередь. |
| `204 No Content` | Действие выполнено, ответ без тела. Например, сервер сохранил настройки. |

## 3xx — дальнейшие действия клиента

Клиенту может потребоваться перейти по адресу из `Location`, выбрать представление ресурса или использовать сохранённую копию.

| Код | Значение |
| --- | --- |
| `300 Multiple Choices` | У ресурса есть несколько вариантов. Клиент может выбрать подходящий. |
| `301 Moved Permanently` | Ресурс перемещён на постоянный адрес. |
| `302 Found` | Ресурс временно доступен по другому адресу. При переходе клиент может заменить `POST` на `GET`. |
| `303 See Other` | Клиент может получить связанный ресурс запросом `GET`, например страницу подтверждения после отправки формы. |
| `304 Not Modified` | При условном запросе сервер сообщает, что сохранённая копия ресурса по-прежнему актуальна. |
| `307 Temporary Redirect` | Временное перенаправление с сохранением метода запроса. |
| `308 Permanent Redirect` | Постоянное перенаправление с сохранением метода запроса. |

## 4xx — проблема с запросом или доступом

Серверу не удалось выполнить запрос в текущем виде или с текущими правами.

| Код | Значение |
| --- | --- |
| `400 Bad Request` | Сервер считает запрос некорректным, например из-за неверного формата. |
| `401 Unauthorized` | Для запроса нужны действительные данные аутентификации. |
| `403 Forbidden` | Сервер понял запрос и отказывает в его выполнении. Например, у пользователя нет прав на действие. |
| `404 Not Found` | Сервер не нашёл запрошенный ресурс или скрывает его существование. |
| `405 Method Not Allowed` | Этот HTTP-метод недоступен для ресурса. Разрешённые методы перечислены в `Allow`. |
| `409 Conflict` | Запрос конфликтует с текущим состоянием ресурса. Например, клиент редактирует устаревшую версию документа. |
| `429 Too Many Requests` | Клиент превысил лимит частоты запросов. |

## 5xx — ошибка на стороне сервера

Сервер или промежуточный шлюз не смог выполнить запрос, например из-за ошибки, перегрузки или сбоя зависимого сервиса.

| Код | Значение |
| --- | --- |
| `500 Internal Server Error` | Внутренняя ошибка помешала выполнить запрос. |
| `502 Bad Gateway` | Шлюз получил некорректный ответ от другого сервера. |
| `503 Service Unavailable` | Сервис временно недоступен, например при перегрузке или обслуживании. |
| `504 Gateway Timeout` | Шлюз не дождался своевременного ответа от другого сервера. |
